# 엔픽던 오퍼레이터 DB

해당 DB 표의 ‘내용’은 개발 시에 참고하기 위한 내용으로 유저가 볼 필요 없는 내용이다.
’툴팁’은 실제 유저가 보게 될 내용으로 사용된다.
공격력은 한손검 오퍼레이터가 방어력이 0인 적에게 기본 공격으로 줄 수 있는 피해의 최댓값을 결정하는 변수이다. 공격력의 10%가 최대 피해량으로 책정된다.(공격력 100 = 적에게 1~10의 피해를 준다) 양손검, 아츠 유닛의 경우 해당 공격력에 무기 타입에 따른 계수를 곱하여 나타내어진다. 자세한 내용은 ‘엔픽던 시스템’ 에 서술되어있다.

### 물리 속성 (7명)

**관리자 (Endministrator)** | 가드 | 한손검

| 항목 | 이름 | 내용 | 계수 | 툴팁 |
| --- | --- | --- | --- | --- |
| 배틀스킬 | 구성 시퀀스 | 물리 피해 + ‘강타’ 적용 |  | 적에게 공격력의 n%의 물리 피해를 입히며 ‘강타’ 한다. |
| 연계기 | 봉인 시퀀스 | 조건: 아군 연계기 적중 시
효과: 물리 피해 + 오리지늄 아츠 결정 부여 |  | 적에게 아군 연계기가 적중 시, 적에게 공격력의 n%의 물리 피해를 주고, 오리지늄 결정을 부착한다.
오리지늄 결정은 물리 이상을 받으면 소모된다. 오리지늄 결정이 어떠한 방식으로든 소모될 때, 적에게 공격력의 n%의 물리 피해를 입힌다. |
| 궁극기 | 폭격 시퀀스 | 대량 물리 피해
추가: 오리지늄 아츠 결정 소모 시 추가 피해 |  | 적에게 공격력의 n%의 물리 피해를 준다. 적이 ‘오리지늄 결정’이 상태일 시, 해당 ‘오리지늄 결정’을 소모하며 추가로 공격력의 n%의 물리 피해를 준다. |
| 고유 기믹 |  | 오리지늄 아츠 결정: 적이 물리 이상을 받을 때 소모 → 소모 시 물리 피해 |  |  |
| 비고 |  | 가드임에도 방어불능 스택을 직접 축적하진 않음.
대신 팀 운용 시 물리 이상 전반에 반응하도록 조정(허브 역할). |  |  |

효과: 물리 피해 + 메인에게 연타 버프 |  | ‘물리 취약’ 혹은 ‘갑옷 파괴’ 상태인 적에게 강력한 일격 적중 시, 적에게 공격력의 n%의 물리 피해를 주고 ‘연타’ 버프를 획득한다. |
| 궁극기 |  | 물리 피해 + 넘어뜨리기 → 물리 피해 + 넘어뜨리기
추가: 연타 소모 시 추가 대량 피해 |  | 적에게 물리 피해를 주고 ‘넘어뜨리기’를 적용한다. 잠시 뒤 한 번 더 물리 피해를 주고 ‘넘어뜨리기’를 적용한다.
이 궁극기로 ‘연타’ 버프를 소모한 경우, 추가로 물리 피해를 준다. |
| 키워드 |  | 연타: 다음 배틀스킬 또는 궁극기 피해 1회 증가 |  |  |

추가: 마지막 스택 소모 시 대량 피해 |  | 적에게 공격력의 n%의 물리 피해를 가하고, 자신에게 ‘철의 서약’ 버프를 3스택 적용한다.
’철의 서약’을 보유 시, 적에게 물리 이상 적용 혹은 ‘보름달 참격’ 적중 시, 공격력의 n%의 물리 피해를 입힌다. 만약 마지막 ‘철의 서약’ 버프일 시, 공격력의 n%의 대량의 물리 피해를 가한다. |

### 냉기 속성 (7명)

**이본** | 스트라이커 | 권총

| 항목 | 내용 | 계수 | 툴팁 |
| --- | --- | --- | --- |
| 배틀스킬 | 지정 위치에 냉기 장치 설치
효과: 3×3 범위 매 턴 냉기 충격파, 종료 시 폭발 → 냉기 피해 + 강제 동결 |  | 지정된 위치에 ‘꽁꽁이’를 설치합니다. ‘꽁꽁이’는 n 턴 간 주변 범위에 매 턴 공격력 n%의 냉기 피해를 가합니다. 이후 폭발하며 주위의 적에게 공격력 n%의 냉기피해를 가하고, 강제로 ‘동결’ 상태를 부여합니다. |
| 연계기 | 조건: 냉기 부착 또는 자연 부착 보유 시
효과: 냉기 피해 + 모든 아츠 부착 소모 → 강제 동결 + 스택 비례 냉기 피해 + 궁극기 충전 |  | 적이 ‘냉기 부착’ 혹은 ‘자연 부착’ 시 사용 가능합니다. 해당 적에게 공격력 n%의 냉기 피해를 가하고, 보유한 아츠 부착을 전부 소모하여 강제로 ‘동결’ 상태로 만듭니다. 이 때 소모한 아츠 부착 스택 수에 비례하여 냉기 피해를 가하고, 궁극기를 충전합니다. |
| 궁극기 | 다음 5회 공격 강화
효과: 공속 0.6~0.8턴, 추가 냉기 피해 자동 부여, 동결 시 추가 피해, 5번째 공격 대폭 강화 |  | 다음 5 번의 기본 공격이 강화됩니다. 공격 속도가 빨라지고, 공격 시 공격력 n%의 냉기 피해를 추가로 입힙니다.
마지막 5번 째 공격은 ‘강력한 일격’으로 취급되고, 공격력 n%의 냉기 피해를 입힙니다. 만약 대상이 ‘동결’ 상태라면 공격력 n%의 냉기 피해를 입힙니다. |

**라스트 라이트** | 스트라이커 | 양손검

| 항목 | 내용 | 계수 | 툴팁 |
| --- | --- | --- | --- |
| 배틀스킬 | 메인에게 저온 주입 부여 (턴 소모 없음)
트리거: 강력한 일격 적중 시 소모
효과: 추가 냉기 피해 + 냉기 부착 |  | 메인 컨트롤 오퍼레이터에게 ‘저온 주입’ 버프를 부여합니다. 라스트 라이트가 메인 오퍼레이터인 경우, 턴을 소모하지 않고 시전 가능합니다.
’저온 주입’ 상태인 메인 오퍼레이터가 ‘강력한 일격’을 적에게 적중 시, 해당 적에게 추가로 공격력n%의 냉기 피해를 가하고, 냉기 부착을 1스택 부여합니다. |
| 연계기 | 조건: 적 냉기 부착 3스택 이상 시
효과: 모든 냉기 부착 소모 → 스택 비례 대량 냉기 피해 + 궁극기 충전 |  | 적이 3스택 이상의 냉기 부착 상태일 때, 사용 가능합니다. 해당 적이 보유한 모든 냉기 부착 스택을 소모합니다. 소모한 스택에 비례하여 냉기 피해를 가하고, 궁극기를 충전합니다. |
| 궁극기 | 3회 대량 냉기 피해
