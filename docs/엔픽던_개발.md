## 2. 파티 시스템

- 파티 최대 **4명** (메인 1 + 팀 최대 3)
- **시작 구성**: 메인 1명 + 팀 1명 선택 후 출발
- **메인 오퍼레이터**: 플레이어가 직접 조작, 기본공격/배틀스킬/궁극기 사용 가능
- **팀 오퍼레이터**: 조작 불가, 연계기만 사용
- 던전 중 **메인 오퍼레이터 교체 없음**

---

## 3. 스킬 체계

### 기본 공격 & 강력한 일격

| 무기 | 콤보 단계 | 총 소요 턴 |
| --- | --- | --- |
| 양손검 | 2단계 | 4턴 (2턴×2회) |
| 그 외 | 3단계 | 3턴 (1턴×3회) |

마지막 단계 공격 = **강력한 일격** (여러 연계기 조건의 트리거)

### 배틀 스킬

- 쿨타임 방식 (매 턴 -1 카운트다운)
- 메인 오퍼레이터만 사용 가능

### 궁극기

- **충전 방식** (공격/처치/배틀스킬/연계기 발동 등 오퍼레이터별 조건)
- 메인 오퍼레이터만 사용 가능

### 연계기

- **턴 소모 없음**
- **쿨타임 있음** (매 턴 -1 카운트다운)
- 동시 활성화 시 **파티 순서대로 큐** 처리
- UI에는 항상 맨 앞 오퍼레이터만 표시

## 4. 영입 시스템

- **5층마다 보스** 처치 → **헤드헌팅 허가증** 드랍 (파티 만원이어도 드랍)
- 허가증 사용 시: 미보유 오퍼레이터 **4명 랜덤 제시**
    - 1명 선택
    - **크레디트** 소모로 리롤 (허가증당 1회)
    - 포기
- 파티 만원 시 영입 → 기존 파티원과 **교체 가능** (교체된 오퍼레이터 **영구 삭제**)
- **5n+1층 확정 상점**: 허가증 판매 (리롤 비용보다 비쌈)
- **크레디트**: 몬스터 드랍, 상자 등 (기존 픽던 골드와 동일)

## 5. 층 구조

```
1계층  1~5층   → 5층 보스  → 6층 확정 상점
2계층  6~10층  → 10층 보스 → 11층 확정 상점
3계층  11~15층 → 15층 보스 → 16층 확정 상점
4계층  16~20층 → 20층 보스 → 21층 확정 상점 ★미래: 엔딩 분기점
5계층  21~25층 → 25층 보스
26층   엔딩
```

## 7. 디버프 시스템

### 7-1. 스택관련형

**아츠 부착** (열기/냉기/자연/전기)

| 상황 | 효과 |
| --- | --- |
| 첫 부착 | 해당 속성 1스택 (최대 4스택) |
| 동일 속성 재부착 | **아츠 폭발** → 해당 속성 피해 + 스택 +1 |
| 다른 속성 부착 | **아츠 반응** 발생 (상태이상형 참고) |

**방어불능 스택** (물리 이상 4종)

물리 이상 종류: `띄우기` / `넘어뜨리기` / `강타` / `갑옷파괴`

| 상황 | 띄우기/넘어뜨리기 | 강타 | 갑옷파괴 |
| --- | --- | --- | --- |
| 스택 없을 때 | 방어불능 +1스택 | 방어불능 +1스택 | 방어불능 +1스택 |
| 스택 있을 때 | +1스택 + 해당 물리 피해 | 전체 소모 + 스택 비례 강력한 물리 피해 | 전체 소모 + 스택 비례 약한 물리 피해 + 물리 피해 증가 디버프 |
- **띄우기 4스택**: 특수효과 없음 (기준값)
- **넘어뜨리기 4스택**: 넉백 1칸 (추후 확정)

### 7-2. 상태이상형 (아츠 반응)

타속성 부착 적에게 아츠 부착 시 기존 스택 전량 소모 후 반응 발생

| 부착 | 반응 | 효과 |
| --- | --- | --- |
| 열기 | **연소** | 소모 스택 비례 열기 피해 지속 |
| 냉기 | **동결** | 소모 스택 비례 이동 불가 (1스택=1턴, 2~3스택=2턴, 4스택=3턴) / 고등급 면역 |
| 자연 | **부식** | 해당 적 공격 시 소량 회복 |
| 전기 | **감전** | 지속시간 동안 받는 아츠 피해 증가 |

**특수 기믹 - 쇄빙**: 동결 상태 적에게 물리 이상 → 동결 소모 + 대량 물리 피해

### 7-3. 행동제어형

`수면` / `기절` / `슬로우` 등 일반적인 CC기

### 기타 디버프

- **취약**: 받는 피해 증가 (물리/아츠/열기/냉기/전기/자연 취약)
- **허약**: 가하는 피해 감소
- **감속**: 이동속도 50% 감소

## 9. 무기 시스템

오퍼레이터별 **고유 무기 고정** (교체 불가). 무기 종류는 데미지 배율뿐 아니라 **공격 사거리**도 결정한다.

| 무기 | 사거리 | 특성 | 패널티 |
| --- | --- | --- | --- |
| **한손검** | 1칸 | 균형잡힌 최소~최대 데미지 | 없음 (기준값) |
| **양손검** | 1칸 | 최소~최대 격차 최대 (×2.0~2.5) | 공격 시 2턴 소모 |
| **장병기** | **2칸** | 사거리 우위 | 인접(1칸) 공격 시 데미지 ×0.75 |
| **권총** | **6칸** | 기준 거리 4칸에서 베스트 | 4칸 초과 시 데미지↓(-10%/칸), 4칸 미만 시 명중↓(-5%/칸) |
| **아츠유닛** | **4칸** | 항상 명중, 배틀스킬 시 충전 +1(최대 3) | 자체 데미지 낮음 (×0.5~0.8) |

> 사거리·거리 보정 상세 수치 및 구현 위치는 `엔픽던_전투시스템.md` §3·§3-1 참조.

## 10. 기질 시스템

- 슬롯: 오퍼레이터당 **1개**
- **공용** 장착 가능
- 구성:
    - **기본 효과**: 데미지 증가 (공통)
    - **특수 옵션** (티어 2+)
        - 공용: 추가 데미지 증가, 연계기 쿨타임 감소 등
        - 무기 유형별: 패널티 감소 / 강점 극대화 / 크로스 타입 효과

## 11. 아츠유닛 충전 효과

아츠유닛 무기는 배틀스킬 시전 시 **충전 +1** (최대 충전량 **3**, 공통). 충전을 소모하는
오퍼레이터별 효과는 오퍼레이터 고유 데이터이므로 **`엔픽던 오퍼레이터 DB.md`** 참조.

**1. 미확정/미결정 사항 목록**

현재 대화에서 아직 결정 안 된 것들:

- 넘어뜨리기 4스택 특수효과
- 이본 궁극기 공속 수치 (0.6턴 or 0.8턴)
- 스노우샤인 쉴드 회복 전환 비율
- 연계기/배틀스킬 쿨타임 구체적 수치
- 기질 티어별 수치 (공용 수식어 14종 배율/확률/지속시간 포함)
- 무기 사거리 거리 보정 세부 수치 (장병기 ×0.75, 권총 -10%/-5%, 방출 +N칸 — 플레이테스트 후 확정)

- 상태이상 시스템 (아직 구체적 수치 미정)
