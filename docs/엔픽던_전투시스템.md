# 엔픽던 전투 시스템 설계

> 기초 전투 구조(속성 피해, 아츠 반응, 방어불능 스택 등 구현된 시스템)는 `엔픽던_구현현황.md` 참조.
> 이 문서는 **피해량 공식 및 공격력(ATK) 시스템 설계 결정사항** 기록.

---

## 1. 공격력(ATK) 개념

기존 SPD는 힘(STR) + 무기 강화치가 피해량을 직접 결정한다.
엔픽던은 이 사이에 **공격력(ATK)** 버퍼를 두어 스킬 계수 설계를 무기 종류와 독립시킨다.

```
STR, 기질 식각, 버프
        ↓
     공격력(ATK)
        ↓
   피해량 계산
```

### ATK 공식 (확정)

```
ATK = 10 + (STR - 10) × 5 + 기질_ATK + 식각 × 5 + 버프
```

| 항목 | 값 | 비고 |
|---|---|---|
| `ATK_BASE` | **10** | 기질 없음 + STR 10 기준 절대 하한 |
| `ATK_PER_STAT` | **5** | STR 1 증가 → ATK +5 |
| `기질_ATK` | **티어별 고정** | T1:+50 / T2:+75 / T3:+105 / T4:+140 / T5:+180 |
| `ENCHANT_ATK_PER_LEVEL` | **5** | 식각 +1 → ATK +5 (min 피해는 별도 +1) |
| 버프 보너스 | 0 (현재) | 추후 버프 구현 시 추가 |

**기준값 예시**:  T1 혼탁 기질 장착 + STR 10 + 식각 0 → ATK **60**, max 피해 **6**
(모든 오퍼레이터의 던전 진입 초기 상태)

## 2. 피해량 공식

### 기준값 (한손검 / 스킬)

```
최솟값 = 1 + 식각 수치 + 스탯 보너스
최댓값 = floor(ATK × 10%) + 스탯 보너스
스탯 보너스 = max(0, 현재 STR - 기질 요구 능력치)
```

예시:
- ATK 100, 식각 0, 스탯 보너스 0 → `1 ~ 10` 피해
- ATK 120, 식각 3, 스탯 보너스 2 → `6 ~ 14` 피해

### 스킬 피해

```
스킬 피해 = damageRoll() × SKILL_MULT
```

- `damageRoll()`은 **무기 배율 없는** 기준값 반환
- 무기 종류와 무관하게 동일 계수 → 스킬 밸런스 설계 일관성 확보
- 툴팁: "공격력의 N% 피해" 형식으로 표기 (ATK = 100 → 계수 1.5 → "150의 피해")

### 기본 공격 피해

```
기본 공격 피해 = ((최솟값 ~ 최댓값) + 스탯 보너스) × 무기 배율 × finalAttackEfficiency()
```

무기 배율은 기본 공격에**만** 적용. 스킬은 자체 SKILL_MULT를 사용.

## 3. 무기 종류별 기본 공격 배율

| 무기 | 최솟값 배율 | 최댓값 배율 | 비고 |
|---|---|---|---|
| 한손검 | ×1.0 | ×1.0 | 기준값 |
| 양손검 | ×2.0 | ×2.5 | 높은 분산, 2턴 소모 |
| 장병기 | ×1.0 | ×1.0 | 인접(1칸) 공격 시 ×0.75 |
| 아츠유닛 | ×0.5 (최소 1) | ×0.8 | 자체 피해 낮음, 배틀스킬 특화 |
| 권총 | ×1.0 | ×1.0 | 기준 거리(4칸) 초과 시 1칸당 -10% (§3-1) |

> 배율 수치: `Hero.java`의 `TWO_HAND_MIN/MAX_MULT`, `ARTS_MIN/MAX_MULT`, `POLEARM_MELEE_MULT`, `HANDGUN_FALLOFF_PER_TILE` 상수. TODO: 수치 확정.

## 3-1. 무기 종류별 사거리 시스템

무기 종류는 **공격 사거리**가 본질적으로 다르다. `Hero.canAttack()`은 메인 오퍼레이터 장착 시
(`activeWeaponType != null`) `operatorCanReach()` 경로로 분기하여 무기 유형별 사거리를 적용한다.
사거리는 `PathFinder` 기반 실제 경로 거리로 판정한다.

| 무기 | 사거리 | 거리 효과 |
|---|---|---|
| 한손검 / 양손검 | 1칸 (인접) | 없음 |
| 장병기 | **2칸** | 인접(1칸) 공격 시 피해 ×0.75 |
| 권총 | **6칸** | 아래 거리 보정 적용 |
| 아츠유닛 | **4칸** | 항상 명중 (`attackSkill()`이 `INFINITE_ACCURACY` 반환) |

### 권총 거리 보정 (기준 거리 4칸)

피해·명중 모두 기준 거리(`HANDGUN_NEUTRAL_DIST` = 4칸)에서 100%이며, **100%를 초과하지 않는다.**

- **피해**: 기준보다 **멀수록** 1칸당 -10% (`HANDGUN_FALLOFF_PER_TILE`), 하한 없음. 기준 이하 거리는 100%.
- **명중**: 기준보다 **가까울수록** 1칸당 -5% (`HANDGUN_ACC_PENALTY_PER_TILE`). 기준 이상 거리는 100%.
  - 여기서 명중은 최종 명중률이 아닌 오퍼레이터의 **명중 스탯**(`attackSkill`)에 곱해지는 계수다.

| 적과의 거리 | 피해 | 명중 |
|---|---|---|
| 6칸 | 80% | 100% |
| 5칸 | 90% | 100% |
| 4칸 (기준) | 100% | 100% |
| 3칸 | 100% | 95% |
| 2칸 | 100% | 90% |
| 1칸 | 100% | 85% |

> 구현 위치: 피해 보정은 `basicAttackDamageRoll()` HANDGUN 케이스, 명중 보정은 `attackSkill()`,
> 사거리 판정은 `operatorReach()` / `operatorCanReach()`.

### 공용 수식어 '방출' 연동

공용 기질 `ReachTrait.reachBonus()`가 `operatorReach()`에 합산되어 무기 종류와 무관하게
사거리를 추가로 늘린다. (TODO: `REACH_BONUS` 수치 확정)

## 4. finalAttackEfficiency()

기본 공격에 적용되는 모든 배율 버프를 **한 메서드에서 집계**하는 구조.

```java
// Hero.java
public float finalAttackEfficiency() {
    float efficiency = 1.0f;
    // 공격 배율 관련 버프 추가 시 여기에만 등록
    return efficiency;
}
```

- 새로운 공격 효율 버프를 추가할 때 이 메서드에만 추가하면 됨
- 스킬 피해에는 미적용 (스킬은 자체 SKILL_MULT 사용)

---

## 5. damageRoll() 분기 구조

`basicAttackMode` 플래그로 기본 공격 / 스킬 분기:

```
damageRoll() 호출
  ├─ basicAttackMode = true  → basicAttackDamageRoll()
  │    (무기 배율 × finalAttackEfficiency() 포함)
  └─ basicAttackMode = false → skillDamageRoll()
       (ATK × 10% 기준, 무기 배율 없음)
```

`onAttackComplete()`에서만 `basicAttackMode = true`로 설정 후 복원.

## 7. 다국어(현지화) 지원

SPD에 `Messages.java` + `.properties` 파일 기반 다국어 시스템이 이미 존재.
일본어(`_ja`), 한국어(`_ko`) 포함 20개 언어 지원 중.

**현재 오퍼레이터 텍스트는 한국어 하드코딩** 상태:
```java
@Override public String name() { return "진천우"; }  // 현재
@Override public String name() { return Messages.get(this, "name"); }  // 다국어 적용 시
```

다국어 대응 시 `assets/messages/operators/` 디렉토리를 새로 만들고
`.properties` 파일에 텍스트를 이전하는 작업 필요.
→ **콘텐츠 완성 이후 현지화 단계에서 처리** 예정.
